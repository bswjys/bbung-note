# 💨 뿡뿡이 기록

가족이 먹은 음식과 속 상태(뿡뿡이)를 귀엽게 남기는 **장건강 다이어리 PWA**예요.
병원 차트 같은 느낌 없이, 따뜻한 크림 화이트 바탕에 살구·민트·연보라 파스텔로 만들었어요.

- **앱 주소** https://bswjys.github.io/bbung-note/
- **저장소** https://github.com/bswjys/bbung-note
- 아이폰 사파리에서 열고 **공유 → 홈 화면에 추가** 하면 앱처럼 쓸 수 있어요. (오프라인에서도 열려요)

## 화면과 기능

### 가족 탭
상단 `가족` 탭에서 **엄마 · 아빠 · 사랑 · 하랑**을 고릅니다. 사람마다 기록과 4칸 표가 완전히 따로예요.
같은 음식이라도 엄마의 `양파`와 아빠의 `양파`는 각자 따로 남습니다.
상단 오른쪽에는 **🔊/🔇 소리**, **🔗 가족 공유**, **💌 뿡밍아웃(공유하기)** 버튼이 있어요.

### 기록하기
- 먹은 음식을 적으면 동그란 미리보기가 **실시간으로 뿅** 하고 바뀝니다.
  - 한국 음식·재료 **168종** 사전(양파 🧅, 사과 🍎, 마늘 🧄, 고구마 🍠, 김치 🥬, 우유 🥛 …)이 이모지와 파스텔 원형 배경을 자동으로 맞춰 줘요.
  - 사전에 없는 음식은 첫 글자 원형 배지로 귀엽게 보여 줍니다.
- `💨💨💨 뿡뿡뿡` · `💨💨 뿡뿡` · `💨 뿡` · `🌿 편안` 네 버튼 중 하나를 누르면 **바로 그 칸에 저장**되고 표로 넘어가요.
  - `저장` 버튼이나 엔터로 저장할 때는 **마지막에 고른 단계**로 담깁니다.
- **같은 사람 안에서는 같은 음식이 중복으로 쌓이지 않아요.**
  이미 있는 음식을 다시 저장하면 새 칩을 만들지 않고 **단계만 옮기고 메모는 그대로** 둡니다.
  (`‘양파’를 ‘뿡’ 칸으로 옮겼어요`처럼 알려 줘요.)
- 맨 아래 **💗 오늘의 건강 일기 TIP** — 18일마다 새로워지는 가스 유발 음식·속 편한 음식·먹을 때 주의점 카드.

### 뿡뿡 표
`뿡뿡뿡 | 뿡뿡 | 뿡 | 편안` 4열 표에 **동그란 음식 그림 + 이름** 칩으로 쌓입니다.
- `오늘 / 7일 / 전체`로 기간을 바꿔 볼 수 있어요.
- 칩을 누르면 **방귀 소리**가 나고 상세 창이 열려요.
  - 소리: 뿡뿡뿡은 묵직한 3연타, 뿡뿡은 통통 2연타, 뿡은 앙증맞은 1번, 편안은 맑은 반짝 소리 (Web Audio로 직접 합성, 오디오 파일 없음)
  - 메모 쓰기, 단계 변경, 음식 그림 바꾸기, 삭제(한 번 더 확인) 가능
  - 메모가 있는 칩에는 💬 표시가 붙어요.

### 💌 뿡밍아웃
`뿡밍아웃` 버튼을 누르면 오늘의 4칸 표를 **1080×1350 PNG 카드**로 만들어요.
`카톡·인스타그램으로 공유`(navigator.share) 또는 `이미지 저장`으로 내려받을 수 있어요.

## 저장과 가족 공유
- 기본은 **이 기기(localStorage)에 즉시 저장** — 인터넷이 없어도 기록·조회가 됩니다.
- **🔗 가족 공유**를 켜면 수유 앱·하트노트와 같은 Firebase RTDB의
  `/bbung_rooms/{방 코드}`에 저장되어 가족이 실시간으로 같은 표를 봐요.
  - 방 코드(2~12글자, 한글 가능)를 정하고 `가족 공유 켜기`
  - `초대 링크 복사`로 보낸 링크(`…/bbung-note/?room=방코드`)를 열면 자동 연결
  - 켜지 않으면 로컬 전용으로만 동작합니다.
  - 연결이 끊겨도 이 기기에 먼저 저장하고, 다시 연결되면 자동으로 맞춰요.
- 다른 사람 데이터와 섞이지 않도록 경로를 `bbung_rooms`로 따로 두었습니다.

## 개발 · 검증

```bash
# 로컬 실행
python3 -m http.server 8000

# 자동 검증 (Playwright + Chromium)
LD_LIBRARY_PATH=/workspace/.browserlibs/lib python3 test_app.py
```

`test_app.py`는 다음을 확인합니다.

- PWA(manifest·sw `bbung-note-v1`·아이콘)와 첫 화면
- 가족 4명 전환, 사람별 기록 분리
- 음식 입력 → 원형 미리보기 실시간 매칭(양파·사과·마늘·우유·미지 음식)
- 4단계 저장, 저장 버튼, 표 이동
- **같은 사람 안 중복 음식 방지**(칩 개수 유지 · 단계 이동 · 메모 보존 · 다른 사람은 독립)
- 칩 클릭 → Web Audio 소리 · 상세 · 메모 저장 · 단계 변경 · 삭제
- 뿡밍아웃 PNG 카드(1080×1350) 생성·다운로드
- 가족 실시간 공유(실제 Firebase 테스트 방에 쓰고 지우기, 초대 링크 동기화)
- 모바일 390 / 데스크톱 1280 가로 넘침 0 · 콘솔 오류 0
- 스크린샷 `downloads/bbung_note/01~04`

## 참고
- 가족 공유는 Firebase 테스트 모드 규칙을 쓰고 있어요. 만료 전에 규칙을 확인해 주세요.
- 기록은 가족의 건강 메모예요. 공유 카드에는 오늘 기록한 음식과 메모가 담기니 보낼 곳을 한 번만 확인해 주세요.
