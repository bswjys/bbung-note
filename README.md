# 💨 뿡뿡이 기록

가족이 먹은 음식과 속 상태(뿡뿡이)를 귀엽게 남기는 **장건강 다이어리 PWA**예요.
병원 차트 같은 느낌 없이, 따뜻한 크림 화이트 바탕에 살구·민트·연보라 파스텔로 만들었어요.

- **앱 주소** https://bswjys.github.io/bbung-note/
- **저장소** https://github.com/bswjys/bbung-note
- 아이폰 사파리에서 열고 **공유 → 홈 화면에 추가** 하면 앱처럼 쓸 수 있어요. (오프라인에서도 열려요)

## 화면과 기능

### 가족 탭
상단 `가족` 탭에서 **엄마 · 아빠 · 사랑 · 하랑**을 고릅니다. 각자의 **동그란 실제 사진**과 이름이 함께 보여요.
사람마다 기록과 4칸 표가 완전히 따로예요. 같은 음식이라도 엄마의 `양파`와 아빠의 `양파`는 각자 따로 남습니다.
상단 왼쪽 **뿡뿡이 얼굴 + `뿡뿡이 기록`을 누르면 어느 화면에서든 `기록하기`로 돌아옵니다.**
상단 오른쪽에는 **🔊/🔇 소리**, **🔗 가족 공유**, **💌 뿡밍아웃(공유하기)** 버튼이 있어요.

### 기록하기
- 인사말 오른쪽에 **지금 고른 가족의 동그란 사진**이 크게 보여요.
- 먹은 음식을 적으면 동그란 미리보기가 **실시간으로 뿅** 하고 바뀝니다.
  - 한국 음식·재료 **387종** 사전(양파 🧅, 사과 🍎, 마늘 🧄, 고구마 🍠, 김치 🥬, 우유 🥛 …)이 이모지와 파스텔 원형 배경을 자동으로 맞춰 줘요.
  - 이모지로는 표현이 어색한 한국 음식·과일 **32종은 전용 그림**(`foods/*.webp`, 128×128)으로 나옵니다 — 참외, 자두, 감, 무화과, 석류, 살구, 대추, 매실, 오이, 애호박, 콩나물, 시금치, 두부, 김, 어묵, 고등어, 김치찌개, 된장찌개, 미역국, 순대국, 김밥, 떡볶이, 떡국, 삼겹살, 비빔밥, 냉면, 짜장면, 칼국수, 부침개, 계란말이, 잡채, 갈비찜.
  - 이름이 조금 달라도 **비슷한 말 사전**이 알아서 찾아요. `샤인머스캣·청포도·거봉 → 포도`, `한라봉·천혜향·레드향 → 귤`, `대추토마토 → 토마토`, `수박화채 → 수박`, `달걀·메추리알 → 계란`, `라떼 → 카페라떼`, `요플레·그릭요거트 → 요거트`, `청양고추·오이고추 → 고추`, `백숙 → 닭고기`, `족발·제육볶음 → 돼지고기`처럼요.
  - 사전에 정확히 없으면 **가장 긴 부분 키워드**로 맞춰요 — `어묵탕 → 어묵`, `사과주스 → 사과`, `김치찌게 → 김치찌개`, `떡만두국 → 떡만둣국`.
  - 사전에 없는 음식은 첫 글자 원형 배지로 귀엽게 보여 줍니다.
- 그림이 잘 맞지 않는 음식은 **`그림 없이 글자만`** 을 눌러 두면, 표와 공유 카드에 **음식 이름 글자만** 깔끔하게 나와요.
- `💨💨💨 뿡뿡뿡` · `💨💨 뿡뿡` · `💨 뿡` · `🌿 편안` 네 버튼 중 하나를 누르면 **바로 그 칸에 저장**되고 표로 넘어가요.
  - `저장` 버튼이나 엔터로 저장할 때는 **마지막에 고른 단계**로 담깁니다.
- **같은 사람 안에서는 같은 음식이 중복으로 쌓이지 않아요.**
  이미 있는 음식을 다시 저장하면 새 칩을 만들지 않고 **단계만 옮기고 메모는 그대로** 둡니다.
  (`‘양파’를 ‘뿡’ 칸으로 옮겼어요`처럼 알려 줘요.)
- 맨 아래 **💗 오늘의 건강 일기 TIP** — 18일마다 새로워지는 가스 유발 음식·속 편한 음식·먹을 때 주의점 카드.

### 뿡뿡 표
`뿡뿡뿡 | 뿡뿡 | 뿡 | 편안` 4열 표에 **동그란 음식 그림 + 이름** 칩으로 쌓입니다.
- 매일 따로 쓰는 표가 아니라 **누적 기록**이에요. 기간 필터 없이 **지금까지 쌓인 기록이 모두** 보입니다. (위에는 늘 `오늘 · 11월 26일 목요일` 날짜가 보여요.)
- `글만 보기`로 정한 음식은 동그란 그림 없이 **음식 이름만 가운데 정렬**로 나옵니다.
- 칩을 누르면 **방귀 소리**가 나고 상세 창이 열려요.
  - 소리: 뿡뿡뿡은 묵직한 3연타, 뿡뿡은 통통 2연타, 뿡은 앙증맞은 1번, 편안은 맑은 반짝 소리 (Web Audio로 직접 합성, 오디오 파일 없음)
  - 메모 쓰기, 단계 변경, 음식 그림 바꾸기(**한국 음식 그림 32개 + 이모지** 중에서 고르기, 맨 위 **`글만 보기 (그림 없이)`** 선택 가능), 삭제(한 번 더 확인) 가능
  - 메모가 있는 칩에는 💬 표시가 붙어요.

### 💌 뿡밍아웃
`뿡밍아웃` 버튼을 누르면 오늘의 4칸 표를 **1080×1350 PNG 카드**로 만들어요. 카드에는 고른 가족의 동그란 사진(위)과 뿡뿡이 캐릭터(아래)가 함께 들어가요.
- **`🖼️ 이미지 저장`** — 아이폰에서는 공유 창이 열리고 거기서 **`이미지 저장`** 을 누르면 사진 앱에 저장돼요. (공유 창이 없는 데스크톱에서는 PNG로 내려받아요.) 카드를 **꾹 눌러** 사진 앱에 저장할 수도 있어요.
- 카드의 음식 자리에도 **한국 음식 그림이 그대로(선명하게)** 그려집니다.
- **`공유하기`** — 카톡·인스타그램 등으로 카드 이미지를 바로 보내요.
- `글만 보기`로 정한 음식은 카드에서도 그림 없이 이름만 나옵니다.

## 저장과 가족 공유
- 기본은 **이 기기(localStorage)에 즉시 저장** — 인터넷이 없어도 기록·조회가 됩니다.
- **🔗 가족 공유**를 켜면 수유 앱·하트노트와 같은 Firebase RTDB의
  `/bbung_rooms/{방 코드}`에 저장되어 가족이 실시간으로 같은 표를 봐요.
  - 방 코드(2~12글자, 한글 가능)를 정하고 `가족 공유 켜기` — 방 코드를 아는 사람은 기록을 볼 수 있으니 가족에게만 알려 주세요
  - `초대 링크 복사`로 보낸 링크(`…/bbung-note/?room=방코드`)를 열면 자동 연결
  - 켜지 않으면 로컬 전용으로만 동작합니다.
  - 연결이 끊겨도 이 기기에 먼저 저장하고, 다시 연결되면 자동으로 맞춰요.
- 다른 사람 데이터와 섞이지 않도록 경로를 `bbung_rooms`로 따로 두었습니다.

## 개발 · 검증

```bash
# 로컬 실행
python3 -m http.server 8000

# 자동 검증 (Playwright + Chromium)
LD_LIBRARY_PATH=/workspace/.browserlibs/lib python3 test_app.py
```

`test_app.py`는 다음을 확인합니다.

- PWA(manifest·sw `bbung-note-v3`·새 방귀 캐릭터 아이콘·음식 그림 프리캐시)와 첫 화면
- **가족 4명 실제 사진**(탭·기록하기 큰 사진·사진 로드·깨진 이미지 0)
- **상단 브랜드 클릭 → 기록하기 복귀**
- **오늘/7일/전체 필터 없음 · 어제 기록도 바로 보이는 누적 표**
- **글만 보기** — 보드 칩·상세·공유 카드에서 그림 없이 글자만
- **한국 음식 그림 32종** — 파일 32개 제공 · 사전 매칭 24종 + 같은 그림 8종 · 미리보기·표 칩·상세·카드에 실제 그림 로드 · 그림 바꾸기 선택 목록 · 글만 보기로 되돌리기
- 음식 입력 → 원형 미리보기 실시간 매칭(양파·사과·마늘·우유·미지 음식)
- 4단계 저장, 저장 버튼, 표 이동
- **같은 사람 안 중복 음식 방지**(칩 개수 유지 · 단계 이동 · 메모 보존 · 다른 사람은 독립)
- 칩 클릭 → Web Audio 소리 · 상세 · 메모 저장 · 단계 변경 · 삭제
- 뿡밍아웃 PNG 카드(1080×1350) · **이미지 저장**(아이폰 공유 시트 / 데스크톱 내려받기) · 공유하기
- 가족 실시간 공유(실제 Firebase 테스트 방에 쓰고 지우기, 초대 링크 동기화)
- 모바일 390 / 데스크톱 1280 가로 넘침 0 · 콘솔 오류 0
- 스크린샷 `downloads/bbung_note/01~12`

## 파일
```
index.html            화면
styles.css            파스텔 디자인
app.js                기록·표·소리·공유 카드·가족 공유
manifest.webmanifest  PWA 설정
sw.js                 오프라인 캐시 (bbung-note-v3)
character.svg         뿡뿡이(방귀) 캐릭터 — 브랜드 마크·공유 카드·아이콘 원본
photos/               가족 사진 160×160 (mom·dad·sarang·harang)
foods/                한국 음식·과일 그림 32종 (128×128 WebP, 원형 알파)
icon.svg / icon-maskable.svg / *.png   아이콘 (character.svg로 생성)
make_icons.py         아이콘 생성기 (character.svg → icon.svg·PNG)
make_foods.py         음식 그림 생성기 (4×4 그리드 시트 → foods/*.webp)
test_app.py           자동 검증
```

## 참고
- 가족 공유는 Firebase 테스트 모드 규칙을 쓰고 있어요. 만료 전에 규칙을 확인해 주세요.
- 기록은 가족의 건강 메모예요. 공유 카드에는 오늘 기록한 음식과 메모가 담기니 보낼 곳을 한 번만 확인해 주세요.
